# Security Policy

## Reporting a vulnerability

Please do not disclose security vulnerabilities in a public issue.

Until a dedicated reporting address is published, open a private report through GitHub's repository security-advisory flow or contact the repository owner directly. Include:

- A clear description of the issue.
- Steps to reproduce it safely.
- The potential impact.
- Any suggested mitigation, if you have one.

We will acknowledge reports as soon as practical and work with you on a responsible disclosure timeline.

## Scope

This policy covers repository-controlled content, automation, and configuration. Reports about third-party tools listed in NeuronFort should be sent to the maintainers of those tools.
