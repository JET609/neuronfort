# Tool evaluation checklist

Use this checklist before recommending a new tool or learning resource in NeuronFort.

## Project quality

- Is there an official website or maintained source repository?
- Is the license clear?
- Is the tool actively maintained or still useful in its current form?
- Does the official documentation explain safe setup and use?

## Fit for NeuronFort

- Does it support defensive security, incident response, monitoring, analysis, secure development, or legal learning?
- Can we describe it in plain language for a newcomer?
- Is the intended use lawful and consent-based?
- Does it avoid encouraging unauthorized access, disruption, evasion, or credential theft?

## How to submit it

Include the official link, a one-sentence description, the defensive use case, and any important setup or licensing note. Keep claims factual and link to the source rather than copying large sections of documentation.
