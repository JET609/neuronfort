# Four-week defensive security learning path

This path is for beginners who want a steady, legal introduction to cybersecurity. Plan for three to five focused hours each week. Use only labs, CTFs, systems you own, or environments where you have written permission.

## Week 1 — Learn how systems communicate

**Goal:** understand the pieces you are trying to protect.

- Learn the roles of IP addresses, DNS, ports, HTTP(S), and TLS.
- Get comfortable in a Linux terminal: files, permissions, processes, and package updates.
- Capture traffic from your own computer with [Wireshark](https://www.wireshark.org/) and identify a DNS lookup and an HTTPS connection.

**Finish line:** explain what happens when you enter a web address in a browser.

## Week 2 — Learn secure web basics

**Goal:** see how common application risks happen and how they are prevented.

- Work through introductory lessons in [PortSwigger Web Security Academy](https://portswigger.net/web-security).
- Run [OWASP WebGoat](https://owasp.org/www-project-webgoat/) locally and complete a beginner lesson.
- Read the [OWASP Top 10](https://owasp.org/www-project-top-ten/) overview.

**Finish line:** describe input validation, authentication, and authorization in your own words.

## Week 3 — Practice detection and investigation

**Goal:** build the habit of looking for evidence before drawing conclusions.

- Review example network logs with [Zeek](https://zeek.org/) documentation.
- Read a few [Sigma](https://sigmahq.io/) rules and note what event each one is trying to detect.
- Explore a beginner exercise on [picoCTF](https://picoctf.org/) or [OverTheWire](https://overthewire.org/wargames/).

**Finish line:** document one suspicious event: what you saw, why it mattered, and what you would check next.

## Week 4 — Turn learning into a repeatable practice

**Goal:** apply the basics to a small, authorized environment.

- Make a simple inventory of your own devices, operating systems, and important accounts.
- Enable updates, MFA, and backups where they are missing.
- Write a one-page mini-report: scope, observations, improvements made, and follow-up actions.

**Finish line:** have a short improvement plan you can revisit in a month.

## Keep going

Repeat the cycle: learn one concept, practice it legally, document what you learned, and strengthen something you own. Depth comes from consistent practice—not from trying to learn every tool at once.
