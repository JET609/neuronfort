# Contributing to NeuronFort

Thanks for helping make security learning more useful and responsible.

## What belongs here

Good contributions include:

- Open-source or freely available defensive-security tools.
- Learning resources with a clear, legal practice environment.
- Corrections to descriptions, links, licensing, or project status.
- Short, practical explanations that help newcomers choose a tool.

Please do not add material that enables unauthorized access, credential theft, destructive activity, evasion, or harassment.

## Before opening a pull request

1. Check that the project is active enough to recommend and link to its official site or repository.
2. Describe the tool in plain language and identify its defensive or educational purpose.
3. Keep additions concise and avoid copying large sections of third-party documentation.
4. Confirm that every link works and uses HTTPS when available.
5. Read and follow the [Code of Conduct](CODE_OF_CONDUCT.md).

## Suggested pull-request format

```md
### What changed
- Added/updated: …

### Why it belongs in NeuronFort
…

### Source
Official project URL: …
```

## Reporting problems

For inaccurate content, broken links, or improvement ideas, open an issue with enough context for someone else to reproduce the problem. For security-sensitive reports, use the process in [SECURITY.md](SECURITY.md).
